นี่คืออะไร
ARTY เป็นโปรแกรมวาดมังงะและภาพประกอบที่ตั้งใจให้ทำงานได้ดีบนคอมพิวเตอร์สเปกไม่สูง
ไฟล์นี้เป็นเวอร์ชันพรีวิวสำหรับทดสอบ ใช้งานได้แล้วแต่ยังไม่เสร็จสมบูรณ์
ขอบคุณที่ช่วยลองใช้และบอกเราเมื่อมีอะไรผิดพลาด

เครื่องที่ต้องใช้ (สเปกต่ำสุดที่เราออกแบบไว้)
  - Windows 10 (22H2, 64 บิต) หรือ Windows 11
  - แรม 4 GB (8 GB จะสบายกว่า)
  - ซีพียู 2 คอร์ 4 เธรด เช่น Intel Core i3-6100U หรือ Celeron / Pentium / Atom 4 คอร์
    (N4120, N100 และรุ่นใกล้เคียง)
  - การ์ดจอ Intel HD 520 / UHD 600, AMD Vega 3 หรือใหม่กว่า การ์ดจอที่อยู่ในซีพียูก็ใช้ได้
  - ฮาร์ดดิสก์หรือ SSD (SSD เปิดโปรแกรมเร็วกว่า) หน้าจอ 1366 x 768 ขึ้นไป
  - เมาส์ หรือเมาส์ปากกา (แท็บเล็ตราคาถูกก็ใช้ได้)
ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องลง Visual C++ หรือโปรแกรมเสริมใด ๆ

วิธีเริ่มใช้
 1. แตกไฟล์ zip ทั้งหมดไปไว้ในโฟลเดอร์ (คลิกขวา แล้วเลือก Extract All)
    อย่าเปิด arty.exe จากในไฟล์ zip โดยตรง
 2. ดับเบิลคลิก arty.exe
 3. Windows อาจขึ้นว่า "Windows protected your PC" เพราะโปรแกรมยังไม่ได้ลงลายเซ็น
    ให้กด "More info" แล้วกด "Run anyway"
ถ้าจะลบ ARTY ให้ลบโฟลเดอร์ทิ้งได้เลย (การตั้งค่าอยู่ที่ %APPDATA%\ARTY ส่วนไฟล์กู้คืนและ log
อยู่ที่ %LOCALAPPDATA%\ARTY ลบด้วยก็ได้ถ้าต้องการ)

งานของคุณมีการป้องกัน
ARTY เก็บสำเนากู้คืนของหน้าที่กำลังวาดประมาณทุก 1 นาที (เมนู ไฟล์ > บันทึกอัตโนมัติ)
ถ้าโปรแกรมปิดเองหรือไฟดับ ให้เปิด ARTY ใหม่ หน้าแรกมีปุ่ม "เปิด / กู้คืน" ซึ่งแสดงงานที่ยังไม่ได้บันทึก
ไฟล์กู้คืนอยู่ที่ %LOCALAPPDATA%\ARTY\recovery
แต่งานที่สำคัญ อย่าลืมกดบันทึก (ไฟล์ > บันทึก) ด้วยตัวเอง

ถ้ามีอะไรผิดพลาด
ทุกครั้งที่เปิด ARTY จะเขียนไฟล์ log เก็บไว้ที่
  %LOCALAPPDATA%\ARTY\logs
  arty-วันที่-เวลา.log    หนึ่งไฟล์ต่อการเปิดหนึ่งครั้ง เก็บ 5 ไฟล์ล่าสุด
  crash-วันที่-เวลา.txt   เขียนเฉพาะตอนที่ ARTY ค้างหรือปิดเองจากข้อผิดพลาด
 1. ใน ARTY เลือกเมนู ช่วยเหลือ > แจ้งปัญหา เบราว์เซอร์จะเปิดแบบฟอร์ม (Google Form) ของเรา
    และมีหน้าต่างโฟลเดอร์ log เปิดขึ้นมาด้วย
 2. เล่าในแบบฟอร์มว่ากำลังทำอะไรอยู่ และเกิดอะไรขึ้น
 3. แนบไฟล์ log จากโฟลเดอร์ที่เปิดขึ้นมา (ไฟล์ .log ล่าสุด และไฟล์ crash-....txt ถ้ามี)
หรือจะเปิดโฟลเดอร์เองก็ได้ที่ ช่วยเหลือ > เปิดโฟลเดอร์ไฟล์ log
โปรแกรมไม่ส่งข้อมูลอะไรออกไปเองเลย คุณเลือกเองว่าจะแนบอะไร ใน log มีเวอร์ชันโปรแกรม
เวอร์ชัน Windows ขนาดแรม จำนวนคอร์ และชื่อการ์ดจอ และอาจมีชื่อไฟล์ที่คุณเปิด
ถ้าครั้งก่อน ARTY ปิดตัวเอง เมื่อเปิดใหม่โปรแกรมจะแจ้งให้ทราบ

ปัญหาที่รู้อยู่แล้ว (ไม่ต้องแจ้งซ้ำ)
  - การเติมสีแบบ "to darkest" บนหน้าที่มีหลายเลเยอร์ (ประมาณ 35 เลเยอร์) อาจทำให้ ARTY
    ค้างราว 1 วินาที
  - หลังกดเลิกทำการย้ายหรือแปลงรูปของส่วนที่เลือก เส้นประวิ่งรอบส่วนที่เลือกอาจยังเป็นของเดิมอยู่ชั่วครู่
  - เคอร์เซอร์ปรับขนาดที่มุมชี้ผิดทิศ เมื่อกรอบที่เลือกยาวและแคบ
  - การเลือกแบบสี่เหลี่ยมหรือบ่วง อาจถูกยืนยันโดยไม่ตั้งใจ ถ้ากด Space ระหว่างลาก
  - ข้อความภาษาไทย: สระ "ำ" อาจแยกออกจากตัวอักษรเมื่อขึ้นบรรทัดใหม่ และเคอร์เซอร์พิมพ์อาจอยู่ผิดที่หลัง "ำ"
  - บนเครื่องสเปกต่ำสุดจะช้ากว่า และหน้ากระดาษใหญ่มากที่มีหลายเลเยอร์ต้องใช้แรมมากกว่า 4 GB
